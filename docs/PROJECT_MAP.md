# Карта проекта: ПрофиМедиа (Content Dispatcher → кабинет амбассадора)

Обновлено: 2026-11-04. Статус: этап 1 собран и проверен локально; публикация демо ждёт «да».

## 1. Что строим
Веб-приложение (PWA), которое ставится на телефон и ПК по ссылке. Две роли:
- **Менеджер** — Content Dispatcher: распределяет обязательные ролики контент-плана между авторами (ТЗ ниже).
- **Автор/амбассадор** — кабинет: назначенные задания, бинго, профикоины, магазин, достижения, опрос (ТЗ-кабинет, Битрикс 29880).

Авторы и амбассадоры — одна сущность в одной базе (предположение, ждёт подтверждения пользователя).

Источники ТЗ:
- Битрикс-задача 29880 (Захар Воскубенко → Ольга Захарова, срок 16.11.2026).

## 5. Правила распределения (как реализовано)
1. Совместимость автора и линии (жёстко): автор активен и не в архиве; категория автора в допустимых (пусто = любая); предмет автора в допустимых (пусто = любой); если у линии обязательный формат, у автора он входит в его форматы (пустой список форматов = любой).
2. Один автор — одна линия не более одного раза.
3. Лимит автора на неделю не превышается.
4. Приоритет: сначала закрываем линии высокого приоритета, внутри приоритета — по раннему дедлайну, затем по названию. Тест сравнивает с полным перебором.
5. Равномерность: среди решений с тем же покрытием выбирается самое ровное по нагрузке (минимум суммы квадратов нагрузок).
6. Закреплённые (ручные) назначения не трогаются при повторном «Распределить», но учитываются в лимитах и покрытии.
7. План объявляется выполненным только когда все линии покрыты и нет конфликтов. Иначе показывается конкретная нехватка.

## 6. Допущения (ждут подтверждения)
- «Авторы» = амбассадоры ПрофиМедиа.
- Предметы, категории и форматы — фиксированные списки (в `constants.ts`), чтобы не плодить опечатки.
- «Предпочтительные форматы» автора считаются форматами, в которых он работает (жёстко при обязательном формате линии).
- «Специализация» — информационное поле, в расчёте не участвует.
- «Нативная интеграция» — текстовое поле (пусто = нет).
- Ручные правки, нарушающие правила, разрешены с красным предупреждением.
- Одна неделя в приложении; история недель — следующий этап.
- Удаление = архив (с возвратом); окончательное удаление отдельной кнопкой.
