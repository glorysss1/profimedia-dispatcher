# ТЗ: Content Dispatcher (текст пользователя 2026-11-04, без изменений)

Создай мобильное веб-приложение Content Dispatcher для UGC-направления онлайн-школы «Профиматика».

Цель приложения: распределять обязательные видео контент-плана между креаторами и амбассадорами так, чтобы все приоритетные контентные линии получили нужное количество уникальных роликов.

Интерфейс на русском языке. Дизайн современный, минималистичный, светлый, с синими акцентами. Приложение должно отлично работать на телефоне, поскольку позже станет Telegram Mini App.

Раздел 1 — «Авторы». Возможность добавлять, редактировать и удалять авторов. Для каждого:

- имя;
- категория: грант, негрант, выпускник или штатный креатор;
- предмет;
- активен ли на этой неделе;
- максимальное количество обязательных видео на неделю;
- предпочтительные форматы;
- специализация.

Раздел 2 — «Контент-план». Добавление обязательных линий с полями:

- название;
- описание идеи;
- приоритет;
- минимальное количество уникальных роликов;
- допустимые категории и предметы авторов;
- обязательный формат, если нужен;
- нативная интеграция;
- дедлайн.

Раздел 3 — «Распределение». Кнопка «Распределить контент-план». После нажатия приложение автоматически назначает темы авторам.

ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА:

- Каждая линия должна получить указанное минимальное количество назначений, если это возможно.
- Нельзя превышать лимит автора.
- Нельзя назначать одному автору дважды одну и ту же линию в рамках недели.
- Нужно учитывать совместимость по категориям, предметам и форматам.
- По возможности равномерно распределять нагрузку.
- Если ограничения несовместимы, показывать конкретную нехватку и не утверждать, что план выполнен.

Менеджер может вручную менять назначения, после чего приложение заново проверяет покрытие и ограничения.

Показывать:

- количество покрытых линий;
- количество назначенных обязательных роликов;
- задания по авторам;
- задания по контентным линиям;
- предупреждения и конфликты.

Добавить экспорт распределения в CSV.

На первом этапе используй демонстрационные данные: 8 авторов и 5 контентных линий. Сохраняй изменения локально в браузере. Пока НЕ подключай Telegram, авторизацию, внешние API и платную ИИ-модель. Не имитируй подключённый ИИ. Сначала создай работающий распределитель, который можно проверить на разных сценариях.
