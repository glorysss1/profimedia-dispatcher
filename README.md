# Content Dispatcher (ПрофиМедиа · UGC)

Веб-приложение (PWA) для распределения обязательных роликов контент-плана между авторами.
Этап 1: демо-данные, хранение только в браузере, без сервера, входа и внешних API.

Демо: https://glorysss1.github.io/profimedia-dispatcher/

Карта проекта, решения и допущения: `docs/PROJECT_MAP.md`. ТЗ: `docs/TZ_DISPATCHER.md`.

## Команды
```
npm install          # зависимости (версии зафиксированы)
npm run dev          # разработка
npm run typecheck    # проверка типов
npm test             # тесты ядра (46 штук, включая сравнение с полным перебором)
npm run build        # сборка в dist/ (с проверкой типов и строгой CSP)
npm run preview      # локальный просмотр сборки: http://localhost:4173
```
Сквозная проверка в браузере: `e2e/e2e.cjs` (см. комментарий в начале файла). Для опубликованной версии: `APP_URL=https://glorysss1.github.io/profimedia-dispatcher/ node e2e/e2e.cjs <папка>`.

## Установка на устройство
Приложение открывается по ссылке и ставится как обычное:
- Android (Chrome): меню ⋮ → «Установить приложение».
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
- Windows/macOS (Chrome, Edge): значок «Установить» в адресной строке.
Нужен HTTPS (на локальном компьютере localhost подходит без него).
